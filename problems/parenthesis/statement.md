Implement an algorithm to print all valid (properly opened and closed) combinations of n pairs of parentheses.

## Example 1:

**Input:** n = 1  
**Output:** ["()"]

## Example 2:

**Input:** n = 2  
**Output:** ["(())","()()"]

## Example 3:

**Input:** n = 3  
**Output:** ["((()))","(()())","(())()","()(())","()()()"]

## Constraints:

- `1 <= n <= 8`
