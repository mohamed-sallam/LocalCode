Write a method to return all subsets of a set.

## Example 1:

**Input:** nums = [1,2,3]  
**Output:** [[],[1],[2],[1,2],[3],[1,3],[2,3],[1,2,3]]

## Example 2:

**Input:** nums = [0]  
**Output:** [[],[0]]

## Example 3:

**Input:** nums = []  
**Output:** [[]]

## Constraints:

- `0 <= nums.length <= 10`
- `-10 <= nums[i] <= 10`
- All the numbers of `nums` are unique
