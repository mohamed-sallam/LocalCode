Write a recursive function to multiply two positive integers without using the * operator. You can use addition, subtraction, and bit shifting, but you should minimize the number of those operations.

## Example 1:

**Input:** a = 3, b = 4  
**Output:** 12

## Example 2:

**Input:** a = 5, b = 7  
**Output:** 35

## Example 3:

**Input:** a = 1, b = 10  
**Output:** 10

## Constraints:

- `1 <= a, b <= 1000`
